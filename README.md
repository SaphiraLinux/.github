# Saphira Linux

Saphira Linux is a small, auditable Linux distribution and software ecosystem built around native, self-hosted infrastructure.

We build software to run because it is useful, understandable and under your control.

## Projects

- **Saphira Linux** — musl-based Linux distribution
- **Saphira LLM** — native C model runtime
- **Saphira Router** — infrastructure control and management
- **Saphira Bridge** — small userspace Ethernet bridge
- **Pocket** — Android applications and agent-facing services
- **SHAMPOO** — persistent memory and knowledge infrastructure

## Principles

- Open protocols
- Self-hosted where practical
- Minimal dependencies
- Evidence before claims
- IPv6 first-class
- Native software rather than SaaS dependency

More projects and documentation are being prepared for public release.
